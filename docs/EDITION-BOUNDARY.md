# 开源版与专业版边界

## 开源版公开能力

- 用户使用自己的 AVE API Key 读取行情；
- 多链 AVE 热榜发现与基础筛选；
- 已知合约风险、流动性、筹码与数据缺失提示；
- 官网、X 人工查看入口及 AVE 代币详细行情与交易页直达；
- AVE 行情 API 配置与只读连接检测，不提供站内签名或下单；
- 本机收藏、备注、提醒、导出和影子表现观察；
- 本地语音提醒及复用已有行情的基础风险形态过滤（不引入 Pro 策略或数据）；
- macOS、Windows 和 Linux 的本机启动方式。

已知的严重风险提示不应被专业版付费墙隐藏。

## 可独立开发的专业能力

- 多钱包关联、同源资金和疑似协同行为研究；
- 持仓结构随时间变化与分发行为分析；
- 多数据源证据冲突处理和长期历史研究；
- 团队协作、持续预警、托管运行和研究报告。

专业能力应部署在独立私有项目或服务中。开源版断开专业服务后仍须能够完成基础扫描；专业服务不可接收用户 API Key、私人备注或完整本机状态，除非用户明确知情并选择上传。

## 尚未决定

- 专业版的具体功能与定价；
- 专业服务地址、授权和隐私政策。

开源版已经采用仓库 `LICENSE` 所列 AGPL-3.0-only 许可证；`package.json` 的 `private: true` 仅禁止误发布到 npm，不改变开源许可证。专业版仍为独立项目。
