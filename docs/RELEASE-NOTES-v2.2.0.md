# v2.2.0｜持续异动提醒与入选理由

这次让雷达不只告诉你“发现了什么”，也告诉你“哪些线索还在持续活跃”。

## 新增：持续异动提醒

- 同一来源、同一交易池的多次有效行情持续活跃后，卡片升级为“持续活跃 · 未核验”，自动排到前排。
- 开启语音后，支持独立的升级提醒；首次线索和升级提醒分别去重，多开页面不重复播报。
- 重复缓存不算新确认。行情过期、条件失效或异动回落后撤下升级高亮；明显回落时显示注意提示。

## 新增：入选理由标签

每张卡片最多显示两个简短标签，例如“成交活跃”“流动性增加”“新入选”。有数据才显示，不用复杂面板，也不把“新入选”当成刚发币。

## 保持轻量

继续按 AVE 免费 API 的请求限制设计，复用已有行情，不新增逐币 API 请求。保留原有动态触手、选中链扫描、自动更新和手动刷新。

观察线索和持续活跃均不代表安全审核通过，不构成买入建议。

## 下载与升级

选择下方 Windows x64 或 macOS 压缩包，完整解压后启动。升级前关闭旧版并备份配置；迁移方式见仓库 README。使用者自己的 API Key、额度账本和运行记录不包含在源码或下载包中。
