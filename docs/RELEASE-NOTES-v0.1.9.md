# Meme雷达开源版 v0.1.9：更简洁、更快、更稳

本次重大更新全面整理了使用体验，让发现、提醒和查看行情更直接。

- 重新整理界面，候选信息更清晰，操作更简洁
- 新增中文 / English 双语音提醒，播报币种自动置顶
- 支持一键直达 AVE 详细行情与交易页面
- AVE 扫描更快、更稳，会根据接口状态自动调整请求节奏
- 候选轮换更及时，减少旧币滞留和重复提醒
- 加强对诈骗盘、貔貅盘、低活跃旧盘和异常走势的过滤
- 新增一键更新，为后续版本升级提供文件校验与异常回滚保护
